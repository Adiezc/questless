# Experiment results

10 seeds x 6 arms x 3 scenarios, 120 days each (180 runs, 45s total, median 1.89 ms per simulated day incl. the scripted player).
Cells: median (min-max) across seeds. Every measure runs from the shock's first day; output and recovery are relative to the no-shock run on the same seed. Generated by `experiments/shock_vs_baseline.py`; raw rows in `runs.csv`.
